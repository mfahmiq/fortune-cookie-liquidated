# Fortune Cookie for the Liquidated Trader

A single fortune cookie line for a crypto trader who has just been liquidated — written for the [make.fun](https://make.fun/c/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c) bounty "Fortune Cookie for the Liquidated Trader".

## The entry

> Your lucky numbers are 3, 7, and the exact price where you should have sold.

Fifteen words, one line, one breath. It opens with the most iconic fortune-cookie phrasing there is — "Your lucky numbers are…" — then breaks the oracular setup with a punchline that lands squarely on the loss: the only numbers that would have been lucky are the price where the trader should have sold. Rueful, warm, and funny about the liquidation rather than cruel about it.

## How to run

```sh
python3 main.py
```

This writes the entry byte-for-byte to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
